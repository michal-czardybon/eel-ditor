# Eel-ditor

Eel-ditor is a dark-themed, plain **text editor** that can wrap **Markdown** content well, and works with **git**, leaving no traces in the **diff**.

## Eel

An eel is a dark and ugly fish that can wrap its long body well, and always slips through unnoticed.

## Design principles

The reasons behind these principles and the decisions made along the way are in [docs/DESIGN.md](docs/DESIGN.md).

1. Be a simple, plain text editor.
2. But allow wrapping long lines and table content to fit the window width.
3. And support semantic operations on lists and tables.
4. Do not pollute the diff (no table reformatting etc.).
5. Allow keeping dozens of files open, and navigating them effectively through a side panel instead of tabs.
6. Offer diff commands (line-based and word-based).
7. Offer git status and commands.
8. Be fast to open and fast to operate.
9. Use keyboard shortcuts as in Notepad++ and Visual Studio.

## Other useful features

- Export to HTML and PDF
- Latin ↔ Cyrillic conversion (Russian, Ukrainian, Serbian, Interslavic, Polish)
- Extended Markdown features (highlight, subscript, superscript, todo lists)

## Line-break conventions

Eel prefers long lines (same as Claude), and word-by-word diff to compare them. This is a pure way to write paragraphs of natural text without thinking when to break, or how to reflow when some lines get longer or shorter after edits. However, when you open existing files these may follow other conventions. Eel can work with them too, and respects their choices. It auto-detects one of several conventions of line-breaks and informs you about what it sees on the toolbar. You can choose whether to make edits using the same convention, or another one. And whenever you want to enforce the currently chosen convention, select the text and press Alt+Q.

## Running

```
dotnet run --project src/EelDitor.App -- [files...]
```

The program runs in a single window: a further start (e.g. double-clicking a file in Explorer) passes the files to the open window. `--new-window` opens a separate window.

## Installer

```
.\build-installer.ps1
```

Builds a self-contained `publish\win-x64\EelDitor.exe` and an Inno Setup 6 installer (`installer\EelDitor.iss`) in `artifacts\installer\`. The program icon (an eel) is generated by `tools/make_icon.py`.

## Tests

```
dotnet test
```

## Structure

| Project | Contents |
|---|---|
| `src/EelDitor.Core` | encodings, EOL, atomic save, file watching, search, diff, git, paragraph breaking, transliteration |
| `src/EelDitor.Markdown` | Markdown parser, table alignment, table operations (no UI dependencies) |
| `src/EelDitor.App` | Avalonia application: window, menus, file panel, Markdown rendering in the editor, diff |
| `tests/*` | xUnit tests, including headless editor tests |

UI texts are in `src/EelDitor.App/Lang/<code>.json`: Polish (`pl`), English (`en`) and Interslavic (`isv`, notes in `isv-notes.md`). A new language is a new file plus an entry in `Loc.Languages`; a test makes sure the keys and `{0}` placeholders match the Polish file. Missing keys take the English text, then the Polish one.

Errors that did not stop the program are written to `%APPDATA%/Eel-ditor/errors.log`.
